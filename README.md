# sas_tools
Utility tools and interfaces for the SmartArmStack framework.

## Packages

| Package | Description |
|---|---|
| [sas_tools](sas_tools) | Interfaces and tools, such as `LeggedRobotDriver` |
| [sas_legged_msgs](sas_legged_msgs) | Messages of the legged robot driver standard |

Clone the repository into the `src` folder of your workspace; `colcon build` finds both packages.

## Design

The legged robot driver architecture is described in [design/UML](design/UML).
